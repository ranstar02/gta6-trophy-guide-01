An offline, open-source trophy guide and tracker for Grand Theft Auto VI on PlayStation 5: all 55 trophies with official names, descriptions and grades, guides in our own words with cited sources, a roadmap to the platinum, missable flags, and a checklist tracker with localStorage progress, export/import, filters and a spoiler setting.

## Run it

```sh
node serve.ts
```
